About · 关于此项目

英超 预测 引擎

一个完全开源、零成本、可持续运营的 AI 足球预测引擎。它不训练模型，不依赖 GPU，只用「提示词工程 + 真实数据 + 前端工程」三件事，让任何拥有浏览器的人都能做英超比分预测。

这是什么

它不是机器学习模型，也不需要数据科学背景。本质上是把一份精心设计的 skill.md 规则文档，作为 system 提示词塞给任意 OpenAI 兼容接口的大模型，让模型在严格约束下推理并输出 JSON。

「规则工程 + 前端工程 + 自动化工程 + 安全流程 = 一个独立开发者的完整技能栈。」 — 项目核心方法论

四层约束架构

LAYER 01
资料库
20 队完整资料写死，只许引用，不许编造
LAYER 02
方法论
近期状态 40%、硬实力 30%、历史交锋 10%、情境因素 20%
LAYER 03
输出契约
严格 JSON 格式，字段、类型、长度全部锁死
LAYER 04
动态情报区
每日手动更新，优先级最高，冲突时以此为准

这套架构解决的问题是：杜绝模型瞎编历史、瞎编伤病、格式飘忽、信息过时。模型很聪明，但也会偷懒——必须用提示词强制约束。

怎么做的

技术栈

  • 规则层 — skill.md v2.1.0 提示词工程（压缩至约 6300 tokens 以适配 Groq TPM）
  • 前端层 — 单文件 index.html，原生 HTML/CSS/JS，零依赖零构建
  • 数据层 — data.json 与代码完全分离，GitHub Actions 每天自动更新
  • 推理层 — Groq 免费 API，模型 openai/gpt-oss-120b，每天 1000 次额度
  • 部署层 — GitHub Pages + Service Worker 离线缓存，零服务器成本

数据从哪来

类型来源用途
比赛数据 football-data.org 积分榜、赛程、完赛比分
球队队徽 ESPN CDN 20 队徽章展示（版权归各俱乐部所有）
AI 推理 Groq 根据 skill.md 生成结构化预测
球员评分 Sofascore / WhoScored / FotMob 焦点球员综合评分（人工整理，写入 skill.md）

自动化流程

GitHub Actions 每天下午 2 点（马来西亚时间）在云端运行 update.js，从 football-data.org 拉取最新数据，写入 data.json 并自动 commit + push。用户本地无需任何操作，网页下次刷新即拿到最新数据。Token 保存在 GitHub Secrets，不进代码库。

隐私与安全

你的数据

  • API Key — 只存于你浏览器的 localStorage，从不发送到除 Groq 官方接口外的任何服务器
  • 历史记录 — 只存于本地浏览器，可随时导出为 JSON 或一键清空
  • 无追踪 — 不接入任何分析统计、不写 Cookie、不收集 IP

分享原理

朋友打开你的网页链接，能看到网页界面，但看不到你的 API Key。他们想使用预测功能，必须自己注册 Groq 获取 Key——消耗的是他们自己的额度，不是你的。
