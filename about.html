英超 预测 引擎

一个完全开源、零成本、可持续运营的 AI 足球预测引擎。现在它不仅提供 18 维深度的 AI 比分预测，还为你每周自动挑选 FPL 梦幻英超的最佳阵容，并实时同步全量伤停情报。

这是什么

它不是机器学习模型，也不需要数据科学背景。本质上是把一份精心设计的 skill.md 规则文档，作为 system 提示词塞给任意 OpenAI 兼容接口的大模型，让模型在严格约束下推理并输出 JSON。

「规则工程 + 前端工程 + 自动化工程 + 安全流程 = 一个独立开发者的完整技能栈。」 — 项目核心方法论

四层约束架构

LAYER 01
资料库
20 队完整资料写死，只许引用，不许编造
LAYER 02
方法论
近期状态 40%、硬实力 30%、历史交锋 10%、情境因素 20%
LAYER 03
输出契约
严格 JSON 格式，字段、类型、长度全部锁死
LAYER 04
动态情报区
每日自动注入官方伤停情报，优先级最高，冲突时以此为准

这套架构解决的问题是：杜绝模型瞎编历史、瞎编伤病、格式飘忽、信息过时。模型很聪明，但也会偷懒——必须用提示词强制约束。

怎么做的

技术栈

  • 规则层 — skill.md v2.2.0 提示词工程（引入数据时效约束，严禁 AI 臆造）
  • 前端层 — 单文件 index.html，原生 HTML/CSS/JS，零依赖零构建
  • 数据层 — data.json 与 fpl.json 双数据源，每日自动注入最新伤停
  • 推理层 — Groq 免费 API，模型 openai/gpt-oss-120b，自动重试防截断
  • 部署层 — GitHub Pages + Service Worker 穿透缓存防污染，零服务器成本

核心功能

  • 智能预测 — 严格 JSON 输出，18 维深度分析（大小球/BTTS/概率校准/命中趋势）
  • 数据动态化 — 每日自动同步英超官方阵容与伤停，强行注入 Prompt 避免 AI 用过期数据预测
  • 防作弊机制 — 已结束比赛禁止预测、唯一赛前定案、实时数据注入、实际比分时间锁
  • FPL 最佳阵容 — 基于官方 API 数据，自动计算每周预测得分最高的 15 人阵容
  • 球员信息 — 多源高清球员照片、进球概率、状态标签、推荐得分球员
  • 比赛选择 — 按轮次 / 按球队双模式，球队下拉显示 38 轮完整赛程
  • 历史追踪 — 自动去重、实际比分自动同步、命中率趋势图
  • 沉浸体验 — 光标光晕、漂浮粒子、3D 倾斜、命令面板、快捷键

隐私与安全

你的数据

  • API Key — 只存于你浏览器的 localStorage，从不发送到除 Groq 官方接口外的任何服务器
  • 历史记录 — 只存于本地浏览器，可随时导出为 JSON 或一键清空
  • 无追踪 — 不接入任何分析统计、不写 Cookie、不收集 IP

分享原理

朋友打开你的网页链接，能看到网页界面，但看不到你的 API Key。他们想使用预测功能，必须自己注册 Groq 获取 Key——消耗的是他们自己的额度，不是你的。
